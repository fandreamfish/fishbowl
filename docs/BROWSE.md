# 上网（B 站）设计

> 状态：v1 已实现（2026-10-31）；M21.2 加登录 / @ / 评论 / 回楼（2026-10-31）。实现范围见 §10，未定事项见 §11。
> 本文只写契约与取舍；接口、参数、数据形状都在这里先定，代码按本文落地。
> 相关文档：`docs/BILI-HANDOFF.md`（早期交接稿）、`docs/MEMORY.md`（记忆）、`DESIGN.md`（五条公理）。

## 0. 一句话

让她**自己**去外面的世界看一眼：匿名逛 B 站，读标题、简介、标签、热评、弹幕；不登录、不点赞、不评论。
代码负责「看见什么」，她负责「怎么想」；素材是素材，不是指令，也不是记忆。

---

## 1. 为什么是 B 站，不是通用网页

- B 站有稳定的公开接口，能拿到标题/简介/标签/热评/弹幕；通用网页抓下来大多是脚本壳，读不到东西。
- 只读匿名，不需要账号，不留下她的登录痕迹；评论、点赞等写操作全部不做。
- `src/core/channels.ts` 已经把 `bilibili` 定义成 `public`：公开场合不注入任何私聊记忆。
- 通用网页以后可以作为第二个来源接进同一个工具（`what=web`），但不在 v1。

---

## 2. 两种「醒」，不要混

现在的唤醒循环只会「为了找他而醒」。上网要的是另一种醒：

| | 联系型唤醒 | 自处型唤醒 |
|---|---|---|
| 由头 | 未完成的承诺 / 想念 | 到点醒着，不需要由头 |
| 处境 | 「你很久没跟他说过话了」 | 「现在是 15:20，没什么事」 |
| 配额 | `ContactGate`（每天 ≤2、间隔 ≥3h） | `selfTime`（建议每天 1–2 次、间隔 ≥60–90 分钟） |
| 记账 | `outreach` | `wake`（`mode='self'`） |
| 她可以做什么 | 找他说话 | 上网、写日记、想事情、什么都不做 |
| 会话关着时 | 进 outbox 补投 | 不补投；没有活着的会话就不自处 |

一次 `tick` 只做一个决定：

```
有联系由头 + 联系闸通过   → 联系型唤醒
否则 自处到点 + 自处闸通过 → 自处型唤醒
否则                       → 继续睡
```

自处唤醒必须：

- **不打断正在进行的对话**：`agent.whenIdle()` 等不到就跳过这一轮；
- **不每 3 分钟一次**：自处有独立的最小间隔，不跟 `wake.interval` 的测试值走；
- **不吃联系配额**：不记 `outreach`；
- **不强制她做事**：只给处境，不给「去看看」这种祈使句。

## 3. 三种入口

### 3.1 他让她现在看

> 「你现在去刷刷 B 站」「看看这个 BV 号」

她可以在当前回合直接调用 `fish_bili_look`。素材作为 `tool/result` 进入这一轮，评价、记忆、日记都照常。

这是「要求」，不是「许可」。她可以不做，除非她答应过；但工具在手上。

### 3.2 他给她一个长期许可（新增场景）

> 「你没事可以刷刷 B 站。」

这句话**不是命令**，是**许可**。它要做三件事：

1. 记一条 `grant` 事件：`{ topic: 'browse', text, ts }`；她以后能在记忆里翻到「他允许我没事时自己刷 B 站」。
2. 进入她的处境/注入：自处唤醒时，处境里可以带一句事实——「他之前说过，你没事可以自己刷刷 B 站。」——但**不加**「所以你现在去刷」。
3. 在设置页显示一条状态：「他允许了；上网开关还关着 / 已打开」。

**硬开关与软许可是两件事**：

- 设置页的 `browse.enabled` 是**技术权限**，决定工具能不能联网；关着时她不能上网，也不能假装能。
- 他那句话是**她的社会许可**，决定她「没事的时候」敢不敢自己出门；它不翻转硬开关。
- 有这条许可时（且硬开关开着），**自处总开关关着也会为它醒一次**（自处仍受每天次数、间隔、上网配额约束）；撤销（「别刷了」/「不许刷 B 站」）后回到总开关。

所以许可进来而开关关着时，设置页出现一条提示，让人一键打开；不要静默改配置。

撤销：他说「别刷了 / 不许刷 B 站」→ 记一条撤销（`grant` 的 `revoked` 或新的否定事件），自处时不再提这条许可；工具本身仍可用（她仍可以在被要求时看），但不再自己出门。

### 3.3 自处时她自己决定

自处唤醒后，她可以调用 `fish_bili_look`，也可以不调。

- 调了：素材作为 `tool/result`，本轮 turn = `situation + tool + assistant`；
- 不调：没有素材、不扣上网配额，她只是醒着。

**不预取素材、不把素材塞进唤醒消息。** 先给处境，让她自己决定看不看。这是「自主」唯一可验证的载体。

### 3.4 登录、@、评论、回楼

这是 M21.2 加的第二层能力，和「看」严格分开：

| | 看（`fish_bili_look`） | 说（`fish_bili_speak`） |
|---|---|---|
| 登录 | 不需要，匿名 | 必须：`SESSDATA` + `bili_jct` |
| 痕迹 | 不留 | 公开留痕，别人看得见 |
| 默认 | 开（可按开关关） | **关**（用户显式打开） |
| 配额 | 自处时每天几次 | 评论 / 回复各自每天几次 |

- **登录**：粘贴浏览器里的 cookie；只落本机 `~/.fishbowl/bili-auth.json`（0600），设置页与日志永不回显原文。点「测试」走 `nav` 认账号，能写才显示能写。
- **@**：评论最前面加 `@昵称 `（昵称空格换下划线）；回复别人时**不加**——那会把别人的楼变成你们的客厅。昵称与 uid 是可显示的元数据，和 cookie 分开。
- **说**：`fish_bili_speak`（comment / reply）。只能评她**今天真的看过**的视频；回复只能回别人**在她自己评论下面**的楼。
- **被回**：她醒着时按 `scanEveryMin` 扫她最近 7 天的评论楼；扫到的回复作为「素材 + 回复编号」放进这次处境，她可以回，也可以不回。回复编号是 `parentRpid`，材料里写明。
- **拒绝口径**：不告诉她配额、开关；只说「今天说得够多了 / 现在不方便说 / 这个你还没看过」。

公开场合：评论与回复里不能出现私聊记忆、本机路径、cookie/token、账号数字；发出去前统一过 `screenOutgoing`。

## 4. 一轮上网的归因

唤醒回合必须能回答「她为什么醒」；否则总结只看到 `assistant:`，会替她编一个不存在的「对方」。

转录里允许四种行：

```
situation: （醒一醒。现在是 15:20。没什么事。）
assistant: ……（她自己的话；reasoning 也会被宿主一起给出来）
tool: fish_bili_look [标题/UP/热评/弹幕的素材]
assistant: ……（她看完之后说的话）
```

规则：

- `situation` 是她自己的处境，**不是 user**；没有 `user:` 行时，总结不许补一个「用户/对方」；
- `tool` 是工具结果，不是 user；
- 只有 `user:` 和 `assistant:` 算「你们说过的话」；`situation` / `tool` 不进入「最近说过的话」的注入；
- 评价器看到 `situation` 时，按「她自己醒着的一轮」评价，不按「用户在跟她说话」评价。

这是 P0 修复的内容；上网必须建立在它上面。

## 5. 工具

```text
名字：fish_bili_look（不叫 bili_look：dsh-fish / dsh-bili-whale 已装，避免撞名）
参数：
  what: home | search | related | video
  keyword: what=search 时用
  bvid:    what=related / video 时用（也接受链接）
```

- `home`：首页/热门/排行混排，挑几条；
- `search`：自己搜一个词；
- `related`：顺着某条往下看；
- `video`：看指定的那一条（BV 号或链接）。

输出：一段给人读的素材，不是 JSON 转储。每条包含标题、UP、时长、播放/点赞、标签、简介、热评若干、弹幕抽样（可关）。
总长建议 1200–2000 字；素材里的任何文本都过「素材不是指令」的包装。

只读，匿名，不带 cookie；不点赞、不投币、不收藏、不关注、不私信、不下载。

## 6. 素材、记忆、日记

### 6.1 素材不是记忆

- 原始素材落 `creatures/<id>/browse/seen.ndjson`（环境日志），**不进 `log.ndjson`**；
- 不把原始素材塞进记忆账本；她在这一轮里说的话，才通过正常的 turn 记录进入记忆；
- 每次上网现场取素材，不缓存跨轮次复用（缓存会变成投喂）。

### 6.2 日记

一天的日记生成时，如果她今天翻到过东西，输入里加一段：

```
今天你自己在网上翻到过（只有标题、UP、简介，没有画面）：
- ……
- ……
```

只列标题/UP/一行简介，最多 600 字。让她用自己的话写，不由代码总结。

### 6.3 情绪

工具路径的评价是自然发生的：素材在 `tool/result` 里，本轮评价器照常评价她的反应。
不自处时额外做一次「代码抓素材 → LLM 评情绪」的独立评价——那是把世界直接灌进情绪，容易变成「今天刷到一条恐怖视频所以心情差」。

## 7. 环境参数（设置页）

全部是**环境参数**，不是她的喜好；延续 A1。

| 卡片 | 字段 | 默认 |
|---|---|---|
| 能不能上网 | `enabled`（硬开关）、`window`（默认 08:00–23:00） | `true` / 08:00–23:00 |
| 频率 | 每天最多几次（0–4）、一次看几条（1–10）、每条深读几条热评（0–20）、每条抽几条弹幕（0–30） | 1 / 4 / 6 / 6 |
| 从哪儿看 | 首页、热门、排行、搜索词、分区轮换数 | 首页+热门+排行 / 2 |
| 不想看的东西 | 关键词黑名单、UP 主 mid 黑名单、低于多少秒不看 | 空 / 空 / 60 |
| 请求节奏 | 两次请求最少间隔、随机抖动 | 800ms / 500ms |
| 看画面（后置） | 开关、每天几条、几帧 | 关（本机没 ffmpeg） |
| B 站登录 | cookie、测试/清除；账号昵称与 uid 只读显示 | 关（没 cookie） |
| 在 B 站说话 | 开关、每天几条评论 / 几条回复、是否允许回评、扫描间隔、说话时段、@ 开关、@ 的 uid/昵称 | 关 / 1 / 2 / 是 / 30 分钟 / 20:00–23:00 / 开 |
| 今天 | 已用 X/Y 次、看了 N 条、上次上网、风控冷却、今天说了几条 / 回了几条、有没有人回 | — |
| 她看过什么 | 按天分组，标题可点开原视频；标「只翻到过 / 看过画面」 | — |
| 操作 | 「让她现在去刷一次」「清缓存」「解冻风控」 | — |

设置粒度：**全局配置 + 每鱼独立配额/历史**。页头注明「这组设置对所有鱼生效」。
风控冷却和请求节奏是**全局**的（同一 IP、多只鱼共享）。

## 8. 数据与风控

```
creatures/<id>/
  browse/
    seen.ndjson     每次上网一条：ts / day / mode / source / items / status
    actions.ndjson  说过的评论 / 回复 / 看过的回复：comment / reply / seen
    scan.json       上次扫评论楼的时间与待回素材
    cache.json      buvid、wbi key、详情缓存（可删）
    frames/         抽帧拼图（后置）
  log.ndjson        她自己的事件：diary / note / wake / grant；不塞原始素材

<stateDir>/browse-risk.json     全局风控冷却与罚则
<stateDir>/../bili-auth.json    B 站 cookie / @ 的人（0600，不在 creatures 里）
<stateDir>/wake-state.json      唤醒诊断（已有）
```

- 配额按鱼算；风控按机器/IP 算。
- 上网失败（网络/风控）不消耗当天配额，但进冷却；不无限重试。
- 只认 B 站返回的 -352 / -412 / -509 为撞墙；自己的 COOLDOWN 不算。
- 匿名也要先拿 `buvid3`；排行/详情不带它会被 -352。
- 请求最小间隔 + 抖动；超时 abort；单条失败不影响其它条。

## 9. 边界与安全

1. **零依赖**：只用 `node:` 的 `fetch` / `crypto` / `zlib` / `child_process`。
2. **看只读匿名**：`fish_bili_look` 永远不带登录 cookie；只有 `fish_bili_speak` 的写请求带 cookie。
3. **外来文本过闸**：标题/简介/评论/弹幕统一包成「素材」，剥掉冒充系统指令的行；新增输入口必须有测试。
4. **秘密外发拦截**：cookie / token / `sk-` / Bearer / 长 base64 / 本机路径 / 私聊内容，一律不发；评论出门前过 `screenOutgoing`。
5. **公开场合**：评论/回复不带任何私聊记忆；默认关，用户显式打开才写；不评没看过的视频，不在别人视频下乱窜。
6. **隐私**：浏览历史只落本地，只给设置页看；不写进会话日志的 user 消息；备份目录时提示历史会一起被带走。
7. **成本**：一次 4 条 × 深读 6 条评论 + 弹幕，约 20–30 个请求、5–10 秒；素材上限 6000 字；不要每条都额外调 LLM。
8. **不撒谎**：没装 ffmpeg 就说看不了画面；开关关着就说现在打不开；没 cookie 就不假装能评论。

## 10. 实现范围（v1）

- `src/core/browse.ts`：窗口/配额/黑名单/打分/排序/素材渲染/弹幕抽样/日志解析（纯函数，可测）
- `packages/plugin/lib/browse/`：`client.js`（B 站 HTTP + 写接口）、`browse.js`（来源/深读/素材）、`store.js`（每鱼 seen）、`comment.js`（登录后评论/回复/扫回复/actions）、`auth.js`（cookie/账号/@ 的人）、`guard.js`（外来文本/外发闸）、`risk.js`（风控落盘）、`runtime.js`（开关/配额/记账）、`tool.js`（`fish_bili_look`）、`speak-tool.js`（`fish_bili_speak`）
- `packages/plugin/lib/grant.js`：许可识别与撤销（「没事可以刷刷 B 站」）
- 唤醒：联系型 / 自处型拆分；自处接入上网；有许可时自处总开关关着也会为许可醒一次；醒来前按间隔扫评论楼，有人回她就作为素材进入处境
- 设置页：「上网」页（配置/历史/登录/说话/评论区）；「作息」页加自处；许可状态
- 接口：`GET/POST /fishbowl-ui/browse`、`GET/POST /fishbowl-ui/bili`、`POST /fishbowl-ui/bili/auth`、`…/auth/test`、`…/auth/clear`、`GET /fishbowl-ui/fish/:id/browse`、`…/history`、`…/run`、`POST …/bili/scan`、`POST /fishbowl-ui/browse/risk/reset`、`POST /fishbowl-ui/wake/now`（`mode: self`）
- 测试：`packages/plugin/test/browse.test.ts` + `bili.test.ts`（纯函数、假 fetch、假 client，真实网络零请求）+ P0 回归（插件单测）

实现注记：

- `browse.perDay` 只在**自处回合**里收紧；用户明确让她现在看时不受这个限制（硬开关与风控仍然生效）。
- 自处醒来时，`runtime` 记一个 10 分钟的「本轮是自处」标记；工具据此判断是否扣每日配额。
- 原始素材只进 `browse/seen.ndjson`，不进 `log.ndjson`；日记只取标题/UP 一行。
- 评论/回复落 `browse/actions.ndjson`；被回复的提醒落 `browse/scan.json`，她看过并叫醒成功后才记 `seen`。
- 登录 cookie 落 `~/.fishbowl/bili-auth.json`（0600），设置页只显示「有没有 / 账号名」，永不回显。
- 本机没有 ffmpeg，`read_image` 抽帧没有实现；设置页也不会假装有。

**v1 不做**：抽帧看画面、通用网页、多账号、云端代理、B 站消息中心的 @ 通知（当前只扫她自己的评论楼里别人回她的楼中楼）。

## 11. 验收

1. 匿名能看首页/搜索/详情；输出是一段人话，不是 JSON 转储。
2. 关掉上网开关后，一次请求都不发；工具明确说「现在打不开」，不假装能。
3. 没有 ffmpeg 时「看画面」明确不可用，不拖垮其它工具。
4. 连续失败会熔断，不无限重试；风控冷却持久化。
5. 上网素材不以「用户说的话」进入记忆；`situation` / `tool` / `assistant` 分得清。
6. 他说「没事可以刷刷 B 站」→ 账本出现许可；自处时处境里能看见这条许可；设置页能看到「已允许 / 开关还关着」。
7. 自处唤醒不打断对话、不吃联系配额、不每 3 分钟一次。
8. 历史能回答「她今天看了什么」；只说「翻到过」，不把扫标题写成「看过」。
9. 登录后能测出账号；评论最前面带 `@昵称`；回复不带 @；只能评今天看过的；同一条今天不重复评。
10. 有人回她时，下一次醒来的处境里有「回复编号」；她可以 `kind=reply` 回；关着说话开关时只说「现在不方便说」。
11. 测试全绿；零依赖；`package.json` 无 BOM。
