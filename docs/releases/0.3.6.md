# 0.3.6

记忆实例缓存归位到 memory 包。

## 改了什么

- `memory/src/instance.ts`：`createInstanceStore({ dirOf, configOf, lockOf, embedder })`——每鱼一个实例的缓存、卸载时释放写锁
- `app/src/memory-store.js` 只剩接线：目录怎么算、配置从哪取、embedder 什么时候建
- 公共接口不变（`createMemoryStore(cfg)`），调用方不用改

## 效果

"缓存 + 生命周期"属于记忆模块自己的事；"目录与配置从哪来"属于应用层。以后换存储或换配置来源，不用动 memory 包。

## 验证

- 接口 / 分层 / 模块加载检查通过
- 七套测试 exit=0
