# 0.4.14

修「新建的会话没有注入」。

## 原因

注入（声音规则、基线状态、名字、日记补写）挂在 `agent/created` 上。新建鱼时顺序是：

```
建会话（触发 agent/created） → 鱼才出生、才拿到住处
```

`agent/created` 触发时这条会话还没有住户，于是走了 `no-occupant` 分支——声音和基线都没注册。会话能看见，但她没有"人格"。

## 改了什么

- `agent/created` 处理拆成 `setupAgent(...)` + 认领流程
- 没有住户时**不再立刻放弃**：每 400ms 重试一次，最多 6 次（约 2.4 秒），认领到就补上声音、基线、名字、日记
- 搬进去的唤醒时机从 700ms 延后到 1.6 秒，确保注入先生效，她第一句话就是"她自己"

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件，再新建一条鱼。这次侧边栏里她的第一句话应该带着她的语气（声音规则已注册），设置页状态里也能看到基础设施注入记录。
