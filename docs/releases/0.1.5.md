# 0.1.5

记忆不再是可关的能力。

## 为什么

- 能力是技能（会不会上网、会不会在外面说话），记忆是"她是不是同一个人"。
- 关掉记忆会把情绪的事件源一起切断：`turn` 事件是评价的落点，情绪靠它重放；关了记忆，她不是忘事，是停止有情绪。
- 如果改成"照记但不读"，开关一开所有过去又会回来——那是失忆表演，不是遗忘。

## 改了什么

- `capabilities` 只剩 `browse`；`memory` 从配置、校验、界面里移除
- 记忆页常驻；「允许她主动翻记忆」留在记忆页里，是检索通道的细节开关
- `turn` 事件的记录不再受任何能力开关影响（情绪永远有新事件可重放）
- 记忆模块不再有 `enabled` 字段

## 验证

- 七套测试全绿（M37/M39 已按新语义改写）
- 分层检查通过

## 升级

刷新设置页。旧配置里的 `capabilities.memory` 会被忽略（等价于记忆永远开启）。
