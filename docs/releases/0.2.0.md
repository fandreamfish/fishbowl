# 0.2.0

破环：适配器不再依赖入口插件。

## 改了什么

- `adapter-dsh/src/http.js` 不再 import `plugin/*`：
  - 宿主实例：用同包的 `./host.js`
  - 唤醒状态与触发：`@fishbowl/app` 的 `wake.js`
  - 登录态读写：`@fishbowl/bilibili` 的 `auth.js`
- 分层检查加第二条规则：**除了入口 `plugin`，任何包都不许依赖入口或兼容层 `src/core`**

## 现在的依赖方向

```
plugin(入口) → adapter-dsh / app / bilibili
adapter-dsh  → app / packages(能力) / 自己的 host
bridge-qq    → app / packages
app          → memory / being / affect / bilibili / schedule / journal / voice
```

## 验证

- 七套测试全绿
- 分层检查通过
- 跨包依赖里不再有 `adapter-dsh → plugin`

## 升级

插件重启一次（进入包结构变了），设置页刷新即可。
