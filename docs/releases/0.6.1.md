# 0.6.1

修搬走后旧房间没归档。

## 原因

`workspaceByPath` 优先用 `registry.get(id)` 的返回值，而它给的是**只读视图**（没有 `archiveSession` 方法），调用时抛 `ws.archiveSession is not a function`，被 catch 后当成失败，于是旧房间留了下来（`lastSessionError` 里能看到这条）。

## 改了什么

- `workspaceByPath` 改为**优先返回带方法的实例**（`list()` 的元素或 `get()` 的实体），只有都没有方法时才退回视图
- `createSession` 的 attach 同样改成"优先带 `attachSession` 的实例"
- `/debug/services` 新增 `wsProbe`：暴露 `listHasArchive` / `getHasArchive`，下次再出问题能一眼定位

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件，再给一条鱼"换房间"试试。旧房间应归档（侧边栏消失）。
