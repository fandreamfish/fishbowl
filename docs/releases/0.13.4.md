# 0.13.4

B 站登录不再把一切都塞在一个输入框里。

## 之前

一个 textarea + 两行长说明：

```
SESSDATA=...; bili_jct=...
只落本机 bili-auth.json（0600）；存完不回显。建议用小号。
从浏览器 DevTools 的 Cookie 头整段粘贴；也可以从 cookies.txt 粘。
```

## 现在

拆成三个独立配置项：

| 字段 | 说明 |
|---|---|
| SESSDATA | 必填；没有它不能登录 |
| bili_jct | 要说话才需要；缺了只能看，不能评论 |
| DedeUserID | 可选；用来标「@ 谁」 |

外加一个可选的「整段粘贴」框：粘进去会自动拆到上面三项（`parsePaste`），然后清空粘贴框。

说明文字也拆行：

- 存到本机 `bili-auth.json`，文件权限 0600
- 存完不回显；建议用小号，别用主账号
- 从 DevTools → Application → Cookies 复制；可以只填前两项

保存时由 `cookieOfFields()` 拼回标准 Cookie 头，服务端解析逻辑不变。
