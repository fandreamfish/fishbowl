# 0.9.4

修「批了但她看不到」。

## 真正的原因（trace 里写着）

```
state inject failed: session append cannot reenter while another append is being published
```

0.7.5 把状态块改到 `turn/start` 注入，但那一刻 DSH 正在发布 turn/start 的 append；同步 inject 会重入，被 DSH 拒绝。于是**她这几轮根本没有收到状态块**——包括"你现在被允许…"和"他答过的…"。

她只能去翻自己的账本，翻的又是 `grant` 事件（我们记的是 `permit`），于是得出"还没批"。

## 改了什么

- 注入改为**让出一拍**再执行（`setTimeout 0`），仍然撞上 reenter 就短暂重试（最多 6 次）
- 回答请求时如果她的会话没开着：写进 outbox，下次打开补投（以前只 wake 活着的 agent，没开就静默丢掉）

## 你现在可以验证

重启插件后跟她说一句话（随便什么），然后看：

1. 她的会话里应出现 `[fishbowl 状态]`，里面有 `你现在被允许: browse …`
2. `trace.ndjson` 里不再出现 `state inject failed`
