# 0.4.8

修 0.4.7 引入的回归：工作区名字又变回目录名。

## 原因

0.4.7 重写 `listScopes` 时，`workspaceNames` 直接用了注册表里的路径作键；而注册表里的写法可能小写、正斜杠（`c:/users/...`），界面拿到的是枚举出来的原生路径（`C:\Users\...`）——又对不上了。这是 0.4.3 修过、0.4.7 重写时弄丢的。

## 改了什么

- 恢复「按返回给界面的路径」生成 `workspaceNames`（内部先用归一化路径查表）
- 会话的 `workspace` 也映射回原生路径，搬家的房间分组不再因为写法不同而丢房间
- 前端分房间改为路径不敏感比较（双保险）

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新。工作区下拉应重新显示「屋子（D:\fish-home）」「大肥鱼的家（…）」。
