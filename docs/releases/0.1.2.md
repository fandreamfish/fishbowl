# 0.1.2

修复 0.1.1 引入的设置页分支断裂。

## 修了什么

- 上一轮改「能力」卡片时误删了 `} else if (page === 'home') {`，导致：
  - 「状态」页执行完状态内容后继续执行「住所」代码，`body` 被覆盖成住所内容（房间 / 请求 / 日记）
  - 「住所」页没有分支可走，显示空白
- 现在分支恢复；并加了一条回归测试：六个页签都必须有分支，且状态分支必须以住所分支收尾。

## 验证

- `node packages/plugin/test/unit.test.ts` 全绿（含新增 M38）
- 其余六套测试不受影响，全绿
- `npm run check:layers` 通过

## 升级

只需刷新设置页（F5）；插件不用重启。
