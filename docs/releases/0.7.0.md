让鱼知道"自己的东西在哪"，并把日记、小纸条落成单独文件。

## 改了什么

**1. 删除旧插件遗留数据**

`C:\Users\24358\.dsh-fish` 已删除（先备份到 `C:\Users\24358\.fishbowl\trash\dsh-fish-legacy-20261101-1520`）。
那是另一套系统的目录，里面的 `她的身份.md`、`diary/2026-10-31.md` 都不是任何一条鱼的。

**2. 告诉她自己的数据目录**

- 搬入提示里写明：`你的东西都在 <creatureDir>：日记（diary/）、小纸条（notes/）、记忆账本`，并要求"想写下、创建、保存的任何东西都放这个文件夹"

**3. 日记落成文件**

`creatures/<id>/diary/<YYYY-MM-DD>.md`，一篇一个文件，头部带时间。

**4. 小纸条落成文件**

`creatures/<id>/notes/<YYYY-MM-DD_HHmmss>.md`，一条一个文件。

事件账本仍是事实来源（文件是可重建的导出），所以不会破坏记忆/投影的一致性。

**5. 历史数据已回填**

两条鱼共 7 条（4 篇日记 + 3 条纸条）已导出成文件。
