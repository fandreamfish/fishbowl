# 0.14.1

修两个问题：开关切页丢失、房间能恢复。

## 1. 开关切页后还原

自动保存有 500ms 防抖，切到「作息」时组件卸载，`clearTimeout` 把还没发出去的那次保存取消了——刚点的开关就丢了。

改法：

- 「上网 / 说话」「作息 / 成长」「记忆」都加了一个 pending 引用
- 组件卸载时把还没落盘的那笔**立刻补发**，不再取消
- 作息与成长改成改完立即保存（不再等防抖）

## 2. 房间消失

`20:40:46` 有一次「换房间」：晶晶被搬到新会话 `cad3cd3c`，旧房间 `22fd866e` 被**归档**（DSH 会把它从侧栏隐藏，文件还在，20 轮对话完整）。

新增恢复接口：

```
POST /fishbowl-ui/fish/<id>/room/restore  { "sessionId": "session-22fd..." }
```

它会：取消归档 → 把她的住处指回旧会话 → 归档当前的新会话。

宿主层新增 `host.unarchiveSession()`（DSH 的 `workspaceRegistry` 本来就有这个方法）。
