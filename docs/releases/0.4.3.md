# 0.4.3

修工作区名字没生效（显示成了目录名）。

## 原因

`workspaceNames` 的键用了归一化路径（小写、`/` 分隔），而界面拿到的 `scopes.workspaces` 是原始路径（`D:\fish-home`）——两边永远对不上，只能退回目录名。

## 改了什么

- `host.listScopes()` 先建「归一化路径 → 标题」表，再**按返回给界面的原始路径**逐条生成 `workspaceNames`
- 顺带说明：会话标题只在活着的会话上取得到（`sessionTitle` 服务），关掉的会话仍显示短 ID

## 验证

- 新增一条接口测试：`/fish` 的 `scopes.workspaceNames` 存在
- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0
