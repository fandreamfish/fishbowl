# 0.4.13

新会话建好后，让她在自己的房间里说第一句话。

## 为什么

DSH 侧边栏不显示"空会话"——没有消息、没有活动的会话会被隐藏。只写标题不够。

## 改了什么

- `injector.js` 新增 `moveInText({ name, occupancy })`：一段舞台提示，告诉她这是她的家、她叫什么
- 建鱼时如果住处是**会话**级：等最多 2 秒找到活着的 agent，然后 `wake` 一次，让她在自己的房间里开口
- 找不到 agent 或唤醒失败只记日志，不影响建鱼

## 她会看到的内容

```
（你刚搬进来。你的名字是「静静」。以后 D:\fish-home 里的这间房间就是你的家：只有你住在这儿，按你的习惯待着就行。）
四处看看，熟悉一下。不用刻意对谁说话；想说什么也可以。
```

## 代价

建鱼时会多一次模型调用（她会回一句）。这是让会话「有内容」的必须代价。

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件，再建一条鱼试试。侧边栏应该出现「X的房间」，并且里面有一句她的话。
