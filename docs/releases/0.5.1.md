# 0.5.1

「清理空房间」移到鱼的列表页，放在「带一条新的回家」右边。

## 改了什么

- 住所页里的清理按钮删掉
- 列表页新增按钮，点击后：
  - 先跑一次 dry-run，把**所有工作区**里没鱼住的房间列出来（按工作区分组）
  - 弹确认（带房间名），确认后才删
  - 删完自动刷新列表
- 后端 `/cleanup/rooms` 支持不传 `path`：不传就逐个工作区处理，返回 `rooms[]`

## 为什么放这里

清理是"整个鱼缸"的维护动作，不属于某条鱼的房间设置。

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新。
