# 0.4.10

「新建会话」时，屋里已经住了鱼也可以选——只要整间屋子没被某条鱼独占。

## 规则改成

| 去处 | 什么时候不能选 |
|---|---|
| 新建会话 · 所在工作区 | 只有**整屋归某条鱼**（工作区级住处）时不能选；屋里只是有鱼住着某个房间 → 可以再开一间 |
| 住进现有工作区（整屋） | 屋里**已经有任何鱼**就不能选（整屋只能归一条鱼） |
| 住进现有会话 | 这个房间被占，或整屋归了别人 → 不能选 |

## 标签也写清楚了

- `屋子（有房间住着 大肥鱼，可以再开一间）（D:\fish-home）`
- `大肥鱼的家（整个屋子已归 鲸鱼娘）`
- 没被占的仍显示 `名字（路径）`

## 后端

冲突规则本来就对：新建会话只跟"整屋被占"冲突，不跟同屋的其他会话冲突。这次只改了前端可选性判断。
