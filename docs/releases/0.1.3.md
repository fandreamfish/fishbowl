# 0.1.3

去掉重复的开关：能力开关现在是唯一入口。

## 改了什么

- 「状态 → 能力」是唯一控制处：上网 / 在 B 站说话 / 翻自己的记忆
- 上网页删掉了「能不能上网」硬开关（保留时段、配额等细节设置）
- 上网页删掉了「在 B 站说话」开关（保留每天条数、查楼间隔、@ 等设置）
- 记忆页删掉了「允许她主动翻记忆」勾选（保留记忆系统本身的配置）
- 保存能力开关时同步写入旧的 `browse.enabled` / `comment.enabled` / `memory.searchTool`，运行时逻辑与展示保持一致

## 为什么这样分

能力 = 她有没有这个本事（决定工具注不注册、页面显不显示）；
页面里的设置 = 有这个本事时，怎么用（时段、配额、预算）。

一个开关只出现在一个地方，避免「关了这个那个还开着」的困惑。

## 验证

- 七套测试全绿（新增 M39：关能力 → 行为字段同步；另一条鱼不受影响）
- 分层检查通过

## 升级

刷新设置页（F5）即可，不用重启插件。
