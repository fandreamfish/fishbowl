# 0.9.3

修「她说已经申请了，但界面上看不到」。

## 原因

`requests()` 在把事件转成视图对象时，只带出了 `id / text / ts / answer`，把 `action / target / uses / ttlMs` 丢掉了。

于是 0.9.2 加的两道过滤：

```js
pendingRequests.filter((r) => r.action)
requests.filter((r) => r.action)
```

把所有请求都当成"没有 action 的旧请求"过滤掉了——她的 4 次申请确实写进了账本，但界面上一条不剩。

## 改了什么

- `requests()` 映射时带上结构化字段
- `pendingRequests()` 同样带出 `action / target`

## 验证

- 新增测试：请求带结构化字段、待答请求能被界面看到
- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件。她账本里那 4 条申请会立刻出现在右下角卡片和设置页里（不用让她重发）。
