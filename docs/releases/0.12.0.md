# 0.12.0

「是否需要许可」变成设置项，并且从"事后审计"改成"事前拦截"。

## 设置在哪

- **浏览页**（状态旁边「上网」）：「看 B 站前要先得到我同意」
- **B 站说话卡片**：「说话前要先得到我同意」

两个都默认**关**。打开后：

```
需要许可才能调用：先用 fish_ask_permission(action=browse) 问他。
需要许可才能调用：先用 fish_ask_permission(action=comment.post) 问他。
```

## 拦截范围

打开「看 B 站要先同意」后：

- **她自处醒来时**也一样拦（不会再出现你截图里"自己刷了"的情况）
- 她只能通过 `fish_ask_permission` 申请 → 你点同意 → 拿到许可（browse 许可今天有效，20 次）
- 没有许可调用 `fish_bili_look` → 直接返回上面那句，不请求 B 站

打开「说话前要先同意」后：

- 没有 `comment.post` 许可 → `fish_bili_speak` 直接拒绝
- 不再走"先发再记 breach"的软路径

关着的时候行为和之前一样：能看，但如果你说过"需要申请"，没申请就看了会记 `breach`。

## 配置

- `browse.requirePermit: boolean`（默认 false）
- `comment.requirePermit: boolean`（默认 false）
- 两条都可以按鱼单独覆盖（写进 `creatures/<id>/config.json`）

## 验证

- 新增测试：默认不要求许可、浏览/说话开关可配置、单鱼配置保留开关
- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新页面。在设置里把开关打开即可。
