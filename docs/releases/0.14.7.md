# 0.14.7

按审计报告收口：设置页的读写链路和几处高危缺口。

## 修复（对应 docs/SETTINGS-CONFIG-AUDIT.md 第 5 节）

1. **读失败不再静默回退全局**：`GET /fish/:id` 失败时，设置页直接报错，不再拿全局值回填、再写进这条鱼的 config.json。
2. **出生后 seed 只读**：单鱼 config 的 POST 在鱼已有 `turn/episode` 时丢弃 seed；只有 UI 的 disabled 不再算唯一防线。
3. **单鱼记忆写入校验**：`POST /fish/:id/config` 带 `memory` 时先跑 `validateMemory`，矛盾值返回 400，不落盘。
4. **状态回包按鱼**：`/browse`、`/bili`、`/browse/run`、`/bili/scan` 与 `fishView.browse` 全部改用 `configFor(cfg, c)`。
5. **capabilities 与 browse.enabled 一致**：`configFor` 以能力开关为权威同步；`normalizeConfig` 在没显式给 capabilities 时跟随 `browse.enabled`。
6. **`memory.enabled` 变成真键**：`normalizeMemory` 输出、`pickMemoryConfig` 保留、`observe`/`tick` 在关闭时直接返回；记忆设置页增加总开关。
7. **`autoApprove` 有 UI**：说话卡片增加「这类事不用每次问（直接发）」。
8. **文案**：不再写「设置对所有鱼生效」，改为按鱼生效。
9. **写入自愈**：`writeFishConfig` 以完整模板打底，旧文件缺子键会在下次写入时补齐。
10. **`/requests` 不再兜住所有 GET**（0.14.4 的关键修复）。
