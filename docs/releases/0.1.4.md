# 0.1.4

能力收敛成两个总开关：上网、记忆。

## 改了什么

- **能力只有两个**：
  - 上网：关掉后没有上网页、没有看视频工具、没有在 B 站说话的工具，自处也不再出门
  - 记忆：关掉后不记、不想、不注入、不提供 `memory_search`，记忆页也消失
- **在 B 站说话**回到上网页，作为上网能力下的细节开关（能力开着时才有意义）
- **翻自己的记忆**回到记忆页，作为记忆能力下的细节开关
- 记忆模块新增总开关 `memory.enabled`；关掉时轮次照常记录情绪，但不写记忆、不整理、不注入记忆内容
- 两个能力互不影响：关记忆不影响上网，关上网不影响记忆

## 验证

- 七套测试全绿（M37/M39 已按新语义改写）
- 分层检查通过

## 升级

刷新设置页（F5）。已有鱼的配置里旧的 `speak` / `memorySearch` 会被忽略，等价于 `memory` 沿用原值。
