# 0.3.0

设置页前端从"一个巨大的 if 链"改成"七个命名页面函数"。

## 约束

DSH 的客户端插件是被拼进一个 chunk 执行的（不是浏览器原生 ES module），所以不能拆成多个文件；这次是**同一个文件内的组件化**。

## 改了什么

`packages/plugin/client.js`：

- 新增 `renderStatus` / `renderHome` / `renderRoutine` / `renderBrowse` / `renderPersona` / `renderMemory` 六个页面函数
- `Section` 里原来 400 多行的 `if (page === ...)` 链，变成十几行的分发表
- 页面函数定义在 `Section` 内部，共享同一组闭包状态（不需要传一堆参数）

## 验证

- 七套测试全绿（含 M38 页面分支回归）
- `node --check` 通过

## 升级

刷新设置页（F5）。如果某页异常，先看 F12 控制台第一条报错，再回退到 `0.2.4`。
