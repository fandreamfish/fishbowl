# 0.3.5

配置 schema 下沉到各能力包。

## 改了什么

- `schedule` 新增 `config.ts`：`normalizeWake` / `normalizeContact` / `normalizeSelfTime` / `pickRoutineConfig`
- `journal` 新增 `config.js`：`normalizeDiary`
- `affect` 新增 `config.ts`：`normalizeAffect`（半衰期 0.1–60 天）
- `bilibili` 新增 `config.js`：`normalizeComment` / `pickCommentConfig`
- `app/config.js` 不再自己写这些块的默认值与钳制，改为调用各包
- `app/cfgkeys.js` 只保留 `pickMemoryConfig`，其余转出

## 效果

加一个"作息"配置项只需要改 `schedule`；加一个"评论"配置项只需要改 `bilibili`。`app` 只负责组合与按鱼覆盖。

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

插件重启一次。
