# 0.10.4

配置缺失时给出提示。

## 提示在哪

1. **设置页「养的鱼」列表顶部**——黄色横幅：

   ```
   fishbowl 配置可能不完整
   · appraiser 不是 deepseek：没有 LLM 评价，记忆总结也不会跑
   · appraiser.apiKey 为空：调用会失败
   · 清醒节律与自处都关着：她不会主动醒来
   常见原因：DSH 设置页保存时重写了 profile 的 cordis.patch.yml，把 fishbowl 那段冲掉了。
   ```

2. **`trace.ndjson` 启动时写一行**：`配置不完整：…`

## 实现

- `app/src/config.js` 新增 `configHealth(cfg)`（纯函数，只报告不改配置）
- `stateView` 带 `health: { ok, issues }`
- 列表页读 `data.health` 渲染横幅
- 插件启动时 `traceWarn('config', …)`

## 验证

- 新增测试：默认配置应提示 appraiser 不对；配好之后自检通过；`/fish` 返回 `health`
- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启 DSH。现在配置已被补回，横幅应**不出现**；如果又出现，说明 profile patch 再次被冲掉了。
