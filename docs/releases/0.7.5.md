# 0.7.5

状态块改成"回合开始注入"，不再在回合之间排队——退出时的"任务进行中"提示随之消失。

## 改了什么

- 状态块从 `turn/end` 移到 `turn/start` 注入：同一回合内就被消费，inbox 不再挂着消息
- 删掉两处会产生"排队消息"的注入：
  - 建 agent 时的基线注入（第一轮会由 turn/start 注入，重复了）
  - "同步到同一只鱼的其它会话"的注入（每个会话自己会在回合开始算）
- 注入内容不变：状态块 + 许可 + 最近对话；格式不变

## 关于 developer 角色

试过把注入的 role 改成 `developer`（避免冒充用户发言），但 DSH 的 `agent.inject` 通道**一律把消息写成 `user/message`**（`dsh-agent-loop.js` 里 `session.append("user/message", message)`），role=developer 会触发会话校验错误。所以这条消息仍然是 user 角色。

好消息是它现在排在**你的消息之后、她开口之前**，而且当回合就被消费——既不影响退出，也不会留到下一轮被当成"你说过的话"。

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0（e2e 测试补了 `turn/start`）

## 升级

重启插件。之后关闭 DSH 时，只要没有回合正在生成，就不该再弹"任务进行中"。
