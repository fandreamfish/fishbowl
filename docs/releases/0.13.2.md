# 0.13.2

修 0.13.0 拆 `host.js` 时漏掉的导入，导致设置页 500。

## 症状

- 「养的鱼」显示 `HTTP 500`、0 条
- `/fishbowl-ui/fish` 与 `/fishbowl-ui/state` 返回纯文本：
  ```
  enumerateScopes is not defined
  ```

## 原因

把作用域函数拆到 `host/scopes.js` 时，`host.js` 只导入了 `findAgent / normPath / workspaceOf`，但 `listScopes()` 调用 `enumerateScopes()`、`sessionDirsOf()` 调用 `scopesRoots()`，两者没导入。模块能加载（检查通过），一调用就 ReferenceError。

同一处还漏了 `fs` 的导入（拆分时被删掉）。

## 修复

- `host.js` 补 `enumerateScopes`、`scopesRoots`、`fs`
- `scopes.js` 导出 `scopesRoots`

## 回归测试

新增三条：

- `host.listScopes()` 返回数组
- `host.sessionDirsOf()` 返回数组
- `host.workspaceByPath()` 不抛

这类"模块能加载、调用才炸"的问题，模块加载检查抓不到，只能靠调用测试。

## 验证

- 分层 / 接口 / 导入检查通过
- 七套测试 + 激活冒烟通过
