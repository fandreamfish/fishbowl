# 0.14.0

每条鱼的配置彻底独立：一份 `config.json` 说了算，改完即存。

## 现在的规则

1. **创建时复制模板**：`binding.birth()` 把当前默认值写一份完整配置到
   `creatures/<id>/config.json`（growth / wake / contact / selfTime / memory /
   browse / comment / capabilities / diary / affect / relation）
2. **已有鱼补齐**：启动时遍历所有鱼，缺的顶层键从当前默认补进去（已有值优先），
   现在 5 条鱼都有一份完整的 config.json
3. **配置页只读写这份文件**：`configFor()` 仍按"文件覆盖默认"合并，但文件已经完整，
   所以页面看到的就是文件里的值，不再被全局默认覆盖
4. **改完即存**：记忆、上网、说话、作息、人设都不再有「保存」按钮；
   输入停顿 500ms 后自动 POST 到 `/fish/<id>/config`
   - 只有 Cookie 仍保留「保存 cookie」：它是密钥，不适合边输边存

## 修掉的复现路径

之前「打开许可开关 → 保存 → 又变回去」有两个原因：

- 页面读的是全局 `/browse`，写的是这条鱼的 `config.json`（读写出处不一致）
- 保存按钮只在点下去时写一次，页面重载又被全局值回填

现在读的是 `/fish/<id>` 的合并配置，写的是同一份文件，且改动自动落盘。

## 代价（要说清）

配置从此**按鱼冻结当前默认值**。以后改全局默认（profile / 默认模板），
不会自动影响已经存在的鱼——要改就得进每条鱼的配置页改。
这是你要的"每条鱼自己一份"，但也是个行为变化。
