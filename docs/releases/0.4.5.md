# 0.4.5

修「新建会话」报「宿主没有会话服务」。

## 原因

我按 `sessions.createSession` 找，但 DSH 里会话就是 agent——真正的入口是 `ctx.agents.create({ sessionId, agentOptions, meta })`（GUI 新建会话也走它）。

## 改了什么

- `host.createSession` 改走 `ctx.agents.create`：
  - 会话 id 自己生成（`session-<uuid>`）
  - 模型取 `agentDefaultModel.currentSelection()`；取不到就退回默认，让工厂自己补
  - 目录用选中的工作区；建好以后尝试 `workspace.attachSession`，让它出现在对应工作区下
- `new-both` 建完工作区后，把注册表 id 传给会话创建，保证能挂上

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0（housing 断言按路径 id 与 registryId 更新）

## 升级

重启插件。然后试一次「新建一个会话」：

- 成功：侧边栏会出现新会话，鱼住进去
- 失败：把红字发我——现在会带出 DSH 工厂的原始错误（比如模型没配），不会再只说"没有会话服务"
