# 0.4.4

新建鱼时，已被占的屋子/房间不再出现在下拉里。

## 改了什么

- 列表页先算出「已被谁住」：工作区住处按路径、会话住处按会话 id，并且**会话住处会把它的工作区也算占掉**（一个工作区只能住一条鱼）
- 三个下拉都用过滤后的列表：
  - 现有工作区 → 只列空闲的
  - 现有会话 → 只列空闲的，且所在工作区没被占
  - 新建会话所在工作区 → 只列空闲的
- 没有空闲项时显示「没有空闲的工作区/会话（可以新建一个）」，不会给一个空下拉
- 后端冲突检查保留（选了已住的仍返回 409），作为双保险

## 验证

- 新增一条接口测试：给已住工作区建新鱼返回 409
- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新设置页。
