# 0.3.2

修复 0.3.x 引入的启动错误（插件无法激活）。

## 修了什么

- `packages/app/src/turn/after.js`：对 `being` / `journal` / `bilibili` 的相对路径少了一层（`app/src/turn/` 需要 `../../../`），导致 `ERR_MODULE_NOT_FOUND: packages/app/being/src/activity.ts`
- `packages/app/src/wake.js`：`wakeStatePath` 只被 `export *` 重导出，没有本地导入，写状态文件时抛 `ReferenceError` 并被外层 `catch` 吞掉——唤醒状态文件一直不写
- `packages/app/src/turn.js`：补 `forgivenessOf` 的 re-export（测试依赖它）
- `adapter-dsh/src/http.js`：补回 `pickMemoryConfig` / `pickCommentConfig` / `pickRoutineConfig` 的 re-export（旧调用方与测试依赖）
- 测试：M38 改成校验新的分发表结构

## 为什么之前没发现

我之前用脚本跑测试时**只数 `[FAIL]` 行**，模块加载失败会直接以非零退出码结束、一行 `[FAIL]` 都没有——于是被当成"全绿"。

现在新增 `scripts/dev/test-all.mjs`：逐个套件跑，**以退出码判定**，`npm run test:all` 已改为用它。

## 验证

- 七套测试 exit=0
- 插件入口、turn、wake、http 四个模块都能单独 import
- 分层检查通过

## 升级

插件重启一次即可。
