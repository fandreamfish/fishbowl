# 0.7.6

修「新建鱼弹窗默认没有工作区下拉」。

## 原因

弹窗打开时（和创建成功后重置时）还在把模式写成旧值 `mode: 'none'`：

```js
setNewHouse({ mode: 'none', id: '', path: '' })
```

而 `none` 已经不是可选项了。下拉框找不到匹配值，就显示第一个选项「在现有屋子里新建一间房」——**看起来像选中了它，实际 state 还是 `none`**，所以依赖 `new-session` 的工作区下拉不渲染。

## 改了什么

两处 `mode: 'none'` 改成 `mode: 'new-session'`：

- 点「带一条新的回家」时
- 创建成功后重置时

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

刷新设置页即可（只改前端）。
