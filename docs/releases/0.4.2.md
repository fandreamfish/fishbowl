# 0.4.2

住处选择显示名字，而不是路径/ID。

## 改了什么

- `host.listScopes()` 补两类名字：
  - 工作区：`workspaceNames`（路径 → 注册表里的标题）
  - 会话：每个会话带 `title`（`sessionTitle` 服务，只有活着的会话能取到）
- 设置页：
  - 新建鱼的「现有工作区」「新会话所在工作区」下拉 → 显示 `名字（路径）`
  - 「现有会话」下拉 → 显示 `会话标题 · 工作区名字`
  - 搬家弹窗的工作区与房间列表 → 同样显示名字；取不到名字时退回目录名/短 ID

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新设置页。
