# 0.3.7

`Creature` 的门面减负：日记 / 小纸条 / 请求拆成 facet。

## 改了什么

- 新增 `being/src/journal-facets.ts`：`hasDiary` / `recordDiary` / `diaries` / `recordNote` / `notes` / `recordRequest` / `answerRequest` / `requests` / `requestCountSince` / `pendingRequests` / `requestDigest`
- `Creature` 上对应的方法改为一行委托（调用方 API 完全不变）
- 逻辑只保留一份，`Creature` 从 328 行降到 311 行

## 为什么这么拆

`Creature` 是"事件重放 + 元数据"的门面。日记/纸条/请求是**事件类型的读写**，不需要挂在门面上；以后加"她自己的清单"这类事件，只改 facet 文件。

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0（日记/纸条/请求的既有断言全部通过）
