# 0.3.3

模块之间只能通过接口交互：每个包一个 `src/index`，跨包不许直接引用内部文件。

## 改了什么

- 新增公开入口：
  - `packages/app/src/index.js`
  - `packages/bilibili/src/index.js`（显式导出，解决 `normalizeCookie` / `isRiskCode` 同名冲突）
  - `packages/adapter-dsh/src/index.js`
  - `packages/journal/src/index.js`、`packages/voice/src/index.js`
- 48 处跨包 import 从"内部文件"改为"包入口"
- `being` 的入口补上 `grant`
- 新增两个检查，都进了 `npm run test:all`：
  - `check:interfaces`：跨包只能 import 对方 `src/index`
  - `check:imports`：所有包入口与插件入口都能真实 import（防 0.3.1 那种"启动才发现"）
- `src/config.json` 挪到 `src/fixtures/wake-config.json`（它是 demo/test 的夹具，不是配置）

## 验证

- 七套测试 exit=0
- 接口检查通过
- 模块加载检查通过（11 个入口全部可加载）

## 升级
