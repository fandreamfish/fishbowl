# 0.12.2

解释「同一句话出现多次」，并减少 system prompt 的无谓抖动。

## 为什么出现多次

那不是同一条消息重复，而是**每次模型请求都会带一遍系统提示**。DSH 把这些请求的 system 记成 `system/message` 事件，所以看起来重复：

```
8 个 turn
12 次模型请求
 8 条 system/message（只在提示词变化时记一次）
```

- `You are an AI agent powered by DeepSeek Harness`：DSH 自己的身份段，每个请求都有
- `你在和一个认识的人用中文聊天。像真人，不像客服，不像写报告`：fishbowl 的语气段（voice），每个请求都有

模型在单次请求里只看到一份，不会叠加；日志里多次是因为一次会话有很多轮、很多步。

## 改了什么

状态块（情绪/记忆/许可/请求回音）之前**每一步都重算**，导致同一轮内 system prompt 反复变化——既写多条日志，也让 DeepSeek 的上下文缓存失效。

现在同一轮内缓存：`turn/start` 时清一次，之后整轮返回同一份文本。轮与轮之间照常更新。

代价没有：情绪和记忆本来就在一轮结束时才变。
