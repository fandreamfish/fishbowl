# 0.6.2

归档改走注册表服务，修「搬走后旧房间没归档」。

## 原因

我把 `archiveSession` 当成**工作区实体**的方法了。它其实是 `WorkspaceRegistry`（服务）上的方法；实体（`list()` / `get()` 拿到的）只有 `attachSession` / `detachSession` 之类。

上一版探针已经证明了这点：`listHasArchive: undefined`、`getHasArchive: undefined`。

## 改了什么

- `host.archiveSession` 改为调用 `workspaceRegistry().archiveSession(sessionId, { stopActivity: true })`
- `/debug/services` 的 `wsProbe` 增加 `registryHasArchive` 与 `entityHasAttach`，下次一眼能区分"服务方法"和"实体方法"

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件。然后：

1. 看 `/debug/services` 里 `wsProbe.registryHasArchive` 应该是 `"function"`
2. 给一条鱼「换房间」，旧房间应归档（侧边栏消失）
3. 之前遗留的那间旧房（`session-412ce0c1…`）可以用「清理空房间」归档掉
