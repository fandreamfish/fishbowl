# 0.14.4

修一个把设置页读接口全部吃掉的路由 bug，并让版本号可见。

## 关键 bug：`/requests` 兜住了所有 GET

`handleRequests` 只检查 `req.method === 'GET'`，不看路径。任何前面没被处理掉的 GET——

- `GET /fish/:id`（设置页回填单鱼配置）
- 任何未知 GET

都会返回 `{ ok: true, requests: [] }`。于是设置页打开单鱼详情时拿到的不是 `fish`，而是请求列表；`fv.fish?.config` 为空，只能退回全局配置。这就是"接口加了、还是不对"的原因：请求根本没到单鱼路由，被 `/requests` 截走了。

已加路径判断：只有 `parts[0] === 'requests'` 才处理。新增测试：未知 GET 必须 404，不能被兜住。

## 版本可见

`GET /fishbowl-ui/debug/services` 现在带 `version` 字段。重启后如果它显示的不是 `0.14.4`，说明 DSH 还在跑旧代码。
