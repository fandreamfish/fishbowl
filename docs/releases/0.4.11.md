# 0.4.11

修 `cannot get required service "agents" in inactive context`。

## 原因

Cordis 里 `ctx.agents` 是**注入属性**：插件上下文没有声明 inject 时，读取它会直接抛错，而不是返回 undefined。我先前写成 `ctx.agents ?? get('agents')`——左边先炸了，右边根本没机会执行。

## 改了什么

- host 增加 `svc(name)`：先 `ctx.get(name)`，再退回 `ctx[name]`，两种情况都包在 try/catch 里
- `listAgents`、`findAgent`、`createSession` 以及 workspace/session/title 服务全部改走 `svc()`
- createSession 顺手兼容服务名 `agents` / `agent`

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件，再试一次「新建会话」。

如果这次报的是别的错（比如"不能在 inactive context 里创建"），说明 `agents.create` 需要调用方的注入上下文，得换成用子上下文创建——把红字发我。
