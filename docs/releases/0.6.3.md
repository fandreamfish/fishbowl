# 0.6.3

修「归档了但侧边栏还显示」。

## 原因

DSH 的 `archiveSession` 只是**停止该会话的后续工作**（`agent/pre-step` 拒绝），它**不从工作区的 `sessionIds` 里摘掉**。侧边栏按 `sessionIds` 渲染，所以归档后照样显示。

## 改了什么

- `archiveSession` 现在做两件事：
  1. `workspace.detachSession(id)` —— 从工作区摘掉，侧边栏消失
  2. `registry.archiveSession(id, { stopActivity: true })` —— 归档，停止后续工作
- 清理空房间改为直接读工作区的 `sessionIds`（而不是我们过滤过归档的列表），这样"已归档但仍挂着"的旧房间也能被清掉
- 任何一步失败都会记录到 `lastSessionError`，不再静默

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件后：

1. 之前那些归档了却还显示的旧房间，点「清理空房间」——它们会被摘掉（`sessionIds` 里还有它们）
2. 再给一条鱼「换房间」，旧房间应当立即从侧边栏消失
