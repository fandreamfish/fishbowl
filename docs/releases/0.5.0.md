# 0.5.0

清理：删掉工作区里「没有鱼住」的会话（含文件）。

## 新增

- `POST /cleanup/rooms`
  - `{ path, dryRun: true }` → 列出这个工作区里没住户的会话（附磁盘目录）
  - `{ path, dryRun: false }` → 先 `detachSession` 从工作区摘掉，再删会话目录
  - 有鱼住的会单独列在 `kept` 里，永远不删
- 设置页「住所」右上角新增「清理空房间」按钮：
  - 先 dry-run 列出要删的名字，弹确认
  - 确认后执行，弹结果

## 安全边界

- 只处理**指定的这一个工作区**里的会话
- 有任何鱼住在里面（会话级或工作区级）一律保留
- 删除前必须经过一次确认（按钮弹窗），API 默认也是 dryRun

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新。之后打开「住所」页，右上角会有「清理空房间」。
