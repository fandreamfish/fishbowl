# 0.4.6

修新建会话后的三个连带问题。

## 原因

1. `createSession` 把目录用 `normPath` 归一化后当真实路径返回（小写、`/` 分隔），于是新鱼的住处写成了 `c:/users/...`，和真实工作区 `C:\Users\...` 对不上
2. 挂工作区时用的是 `registry.list()` 返回的**视图**，不是真实 Workspace 实例，`attachSession` 静默失败 → 侧边栏不显示
3. 住处路径比较是严格字符串相等，大小写/分隔符不同就认不出是同一间屋子

## 改了什么

- `createSession` 用 `path.resolve` 保留原生路径；挂载改为 `registry.get(id)` 拿真实实例，返回值带上 `attached`
- `tenancy` 新增 `samePath()`：住处匹配、冲突检测都改成大小写/分隔符不敏感
- `views.allScopes` 对工作区按归一化路径去重，避免同一间屋子出现两份（`C:\x` 与 `c:/x`）
- 新增两条路径写法不一致的测试

## 说明

已经建出来的那条鱼（鲸鱼娘）住处里存的是旧写法；因为匹配改成了路径不敏感，她仍然能被认出。下次重启后她应该会重新落到「大肥鱼的家」名下。
