# 0.6.6

继续修"新房间没有工具"。这次有证据。

## 证据

解压 `session-c4bea5f4…` 的事件流，类型统计里**没有 `agent-preset/selected`**——说明 preset 根本没挂上。DSH 只是在写会话时记了权限预设（`permission/preset: workspace-write`），agent 的工具集来自 agent preset，而那一跳没发生。

她的工具列表仍然只有 `working_directory` / `load_workspace_dependencies` / `memory_search` / 两个 B 站工具。

## 改了什么

- `createSession` 挂 preset 改为：
  1. `agentPresets.resolve(undefined)`；失败就 `presets.list()` 取第一个
  2. 记录 `lastCreate = { hasPresets, presetId, presetError, setupCalled }`
  3. **挂不上就直接报错**（而不是悄悄建一个没手的房间）
- `/debug/services` 暴露 `lastCreate`，下次能直接看到是"没有 agentPresets 服务"、"resolve 失败"还是"列表为空"

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0
