# 0.13.5

修「打开许可开关，保存后又变回去」。

## 原因

「上网」页读配置和写配置不是同一份：

- 读：`GET /browse` → **全局默认值**
- 写：`POST /fish/<id>/config` → **这条鱼自己的 config.json**

保存其实成功了（文件里 `requirePermit: true`），但保存后页面重新加载，又拿全局默认值把开关盖回 `false`。同样的坑也存在于「在 B 站说话」的评论区设置。

## 修法

页面加载改成读**这条鱼的合并配置**：

```js
const fv = await getJson(API + '/fish/' + f.id)
setCfg(fv.fish?.config?.browse || b.config)
setComment(fv.fish?.config?.comment || bl.comment)
```

保存仍写 `config.json`；读回来的是同一条鱼的配置，不再被全局值覆盖。

## 验证

- 服务端实测：POST 后 `requirePermit=true`，GET 也是 `true`，`config.json` 已落盘
- 七套测试通过
- `client.js` 语法检查通过
