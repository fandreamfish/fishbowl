# 0.7.1

修「大肥鱼的家」从工作区列表里消失。

## 原因

「大肥鱼的家」的工作区路径是 `C:\Users\24358\.dsh-fish\home`——就在你让我删掉的 `.dsh-fish` 里面。目录被删后，我们的工作区枚举（`enumerateScopes`）会因为"路径不存在"解不出这个工作区，于是它从列表里消失了。

## 改了什么

- 工作区列表改为以 **DSH 注册表为准**：即使目录被删，也照样列出来（名字还在）
- `createSession` 建会话前 `mkdir -p` 目标目录：目录没了就重建，不会因为缺目录而失败
- 已经把 `C:\Users\24358\.dsh-fish\home` 重建为一个**空目录**（不含任何旧文件）

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新。「大肥鱼的家」应该重新出现在换房间的工作区列表里（空的）。
