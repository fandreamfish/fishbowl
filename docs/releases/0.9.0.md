# 0.9.0

许可改成"约定 + 审计 + 一条窄地板"。

## 语义

| 层 | 行为 |
|---|---|
| 硬地板 | 系统级破坏命令（format / diskpart / shutdown / 删盘符或系统目录）直接不执行 |
| 约定 | 在 B 站说话不再被许可硬拦：没有许可也能发，但会被记下来 |
| 审计 | 没等同意就发 → 写 `breach` 事件；状态块里点出来；设置页时间线可见 |
| 回应 | 请求获批 → 签发 `permit`（范围/次数/期限）；她下一轮能看到"你现在被允许…" |

## 改了什么

- 新增事件 `permit` / `permit-used` / `breach`（`being/src/permits.ts`）
- 回答"同意"时会签发许可（默认 1 次 / 2 小时，按请求里的字段）
- 状态块新增两行：`你现在被允许: …`、`没等他同意就做过: …`
- `fish_bili_speak` 去掉硬拦：没许可也发，成功后记 `breach`
- 停止自动生成模糊请求；请求只来自 `fish_ask_permission`
- 设置页时间线能看懂这三种事件
- 硬地板：`pwsh`/`bash` 里的系统级破坏命令直接拒（很窄，防的是手滑和走偏）

## 说清边界

这不是安全边界。她有 shell、有完全文件权限，理论上仍能：读 cookie 直接调 B 站接口、改自己的账本伪造许可、改配置关掉审计。

我们选择的是：**她可以做，但你会知道**。被发现会有关系上的后果（状态块里点出来、影响情绪、你可以在设置页看到）。真锁死要拿掉她的工具，那就没活人感了。
