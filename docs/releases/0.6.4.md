# 0.6.4

清理空房间改成"先选工作区，再清理"。

## 改了什么

- 点「清理空房间」不再扫全部工作区，而是弹一个工作区列表
- 选中一个屋子 → dry-run 只查这个屋子 → 确认 → 归档
- 对话框里写明了：只处理这一个屋子；没鱼住的房间会被归档（侧边栏隐藏、文件保留）

## 为什么改

上一版清理会遍历**所有**工作区，包括 `D:\fish-memory` 里你自己的 10 个对话——那些不是"空房间"，只是没有鱼住。误点一次就会把它们归档掉。现在必须明确选一个屋子。

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新。

之前归档了却还显示的那些旧房间仍在 `sessionIds` 里：现在选「屋子」清理一次，它们会被摘掉。
