# 0.3.4

两套状态块渲染合并成一套。

## 改了什么

- `memory/src/render.ts` 新增 `renderStateBlock(input)`：纯状态块（名字 / 情绪 / 六个旋钮 / 承诺 / 活动 / 折叠 / 请求 / 快照声明）
- 抽出 `affectBiasLines()` 与 `SNAPSHOT_NOTE`，`renderText()` 与 `renderStateBlock()` 共用——旋钮格式与结尾声明只有一份
- `app/src/injector.js` 的 `summaryText` 改为一行委托：`renderStateBlock({ ...memory, bias, affect })`
- 保留了旧签名与旧字段（semantics / procedures / self / activity / folded / requests），调用方不用改

## 效果

QQ 桥（公开场合与兜底）和 DSH 注入现在用的是同一份格式。以后改状态块只改 `memory/src/render.ts` 一处。

## 验证

- 分层 / 接口 / 模块加载三项检查通过
- 七套测试 exit=0（`summaryText` 的既有断言全部仍然成立）

## 升级

插件重启一次。
