# 0.7.3

修成长率一保存就变回 1.00。

## 原因

保存的接口本身是对的（我实测：POST `growth=2.5` → 返回 2.5 → 重新加载还是 2.5）。问题在前端：

`load()` 每次刷新都会执行

```js
setGrowth(d.config.growth)   // d.config 是「全局配置」，默认 1
```

而点保存后 `act()` 会重新 `load()`，于是滑杆被全局默认值覆盖回 1.00——你选的值其实已经存进鱼自己的配置里了，只是界面被刷成了全局值。

## 改了什么

- 删掉 `load()` 里用全局配置覆盖成长率的那行
- 新增一个 effect：**按当前查看的鱼**取 `fish.config.growth` 回填滑杆
  - 拖动时不受影响（data 没变）
  - 保存后刷新，回填的是这条鱼真实保存的值

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

刷新设置页即可（只改了前端）。
