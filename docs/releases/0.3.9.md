# 0.3.9

修「节律已开，但设置页的状态一直是空」。

## 原因

唤醒循环只遍历**活着的会话**，并且只给"这条鱼正好住在这个活会话里"的情况写检查记录：

```js
for (const agent of host.listAgents()) {
  const creature = binding.resolve({ sessionId, workspace })
  if (!creature) continue      // 会话没开 → 什么都不记
  ...
  report.push(...)
}
```

两条鱼的住处是 `session-295c…` / `session-412c…`，当时活着的会话是 `session-cd48…`（本对话），于是 `entries` 恒为 `[]`，卡片只能显示"还没有检查记录"。

另外卡片取的是 `entries[0]`，没有按当前查看的鱼过滤——两条鱼都有记录时也会显示错人的。

## 改了什么

- 唤醒循环改为**遍历所有鱼**，再按住处匹配活会话；匹配不到就记一条 `live: false`（联系型仍会写进 outbox）
- 检查记录里新增 `live` 字段
- 状态卡按 `entry.creature === 当前鱼名` 取记录；`live === false` 时显示「会话没开（她叫不醒，联系会进待送）」

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0（含 M26 唤醒集成）

## 升级

插件重启一次。重启后「现在的状态」应至少显示：最近检查时间、想念值、门控原因；如果鱼的家没开着，会明确写「会话没开」。
