# 0.4.9

住处下拉：已住的工作区/会话不再隐藏，改为**列出但禁用**，并标注被谁占。

## 为什么

0.4.4 为了"不让选已住的"直接把它们过滤掉了——结果带名字的那两个（屋子、大肥鱼的家）恰好都被占，于是一个都看不见，看起来像"名字又变回目录名了"。实际上名字表是对的（`屋子`、`大肥鱼的家` 都在），只是被过滤掉了。

## 改了什么

- 工作区下拉：全部列出，已住的 `disabled`，显示「名字（已被 大肥鱼 占）（路径）」
- 会话下拉：全部列出，已住的或所在屋子已住的 `disabled`，同样标注
- 去掉"没有空闲的"占位（现在总是能列出全部）
- 删除不再使用的过滤变量

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0
