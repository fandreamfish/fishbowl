## 结构

- **状态渲染统一**：新增 `app/src/state.js::composeState`，DSH 与 QQ 共用；QQ 渠道只放状态，不再各自拼一份（之前 QQ 看不到许可/请求/违约）
- **数据根显式化**：`cfg.dataRoot` / `cfg.stateDir` / `cfg.homeRoot`，`scopes.json`、`ui-config.json`、`wake-state.json`、`trace.ndjson` 都挪到数据根（带一次迁移）；transfer 不再用 `dirname` 推导
- **配置单一来源**：`dataRoot/config.json` 保存上次生效的配置（不含 apiKey），DSH 重写 profile 时兜底
- **许可策略收拢**：新增 `being/src/policy.ts::checkPermission/usePermit`，浏览与说话工具不再各自拼许可判断
- **host 拆分第一步**：工作区/作用域纯函数移到 `adapter-dsh/src/host/scopes.js`（host.js 573 → 482 行）
- **记忆 tick 去重**：轮末、十分钟清扫、打开房间三处共用 `tickMemory`，同一只鱼同时只跑一个
- **轻量提醒接口**：`GET /fishbowl-ui/requests` 只返回待答请求，右下角提醒不再每 20 秒拉全量 `/fish`
- **CI**：`docs/CI.md` 记录做法；当前 PAT 没有 `workflow` scope，GitHub 拒绝推送 workflow 文件，所以没有直接提交 `.github/workflows`
