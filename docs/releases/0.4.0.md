# 0.4.0

新建鱼时可以直接选住处：不选、选现有的、或者顺手建一个新的。

## 改了什么

**前端（新建鱼弹窗）**

- 新增「住处（可选）」下拉：
  - 先不安排
  - 住进现有工作区（下拉列出当前工作区）
  - 住进现有会话（下拉列出当前会话）
  - 新建一个工作区（填目录）
  - 新建一个会话（填目录）
  - 新建工作区 + 会话（填目录）
- 创建请求带上 `housing` 字段

**后端**

- 新增 `app/src/housing.js`：`normalizeHousing` / `housingToOccupancy`，把选择翻译成住处，必要时真的去建
- `adapter-dsh` 的 host 增加 `createWorkspace(path)` 与 `createSession({ workspaceId? , path? })`（走 DSH 的 `workspaceRegistry` 与 `agents.createSession`）
- `POST /fish` 接受 `housing`；建失败返回 400 并带上原因（比如"目录不存在"）

## 行为

- `new-both`：先登记工作区，再在里面建一个会话，鱼住在**会话**里（这样同一工作区的其它会话不会把她抢走）
- 不选住处：和以前一样，创建后在「住所」页再安排
- 住处冲突仍按原逻辑检查（一个工作区只能住一条鱼）

## 验证

- 新增 9 条 housing 单测（含 new-both 的创建顺序）
- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

刷新设置页（F5）。
