# 0.7.7

修「新鱼认领旧系统的过去」。

## 发生了什么

鲸鱼娘（`d72f783f`）是新建的，账本空的。她搬进 `D:\fish-home` 后自己翻文件，找到了：

```
C:\Users\24358\.fishbowl\trash\dsh-fish-legacy-20261101-1520
```

那是我删除旧插件数据时留的备份（里面有旧系统的 `diary/2026-10-31.md`、`说明.md`、`她的身份.md`）。她读了，判断"这是我的过去"，然后：

- 把旧日记复制进自己的 `diary/2026-10-31.md`
- 把旧 `events.jsonl` 复制成 `notes/旧经历-2026-10-31.jsonl`
- 写了自己的 `diary/2026-11-01.md`，说"昨天我写了篇日记"
- 更新了 `D:\fish-home\房间笔记.md`，把这条假历史写了进去

**这不是记忆串了，是她在没有护栏的情况下从 trash 里认领了别人的过去。**

## 改了什么

- 删掉那个 legacy 备份（你之前就说过直接删；我当初留备份是多余的）
- 删掉她文件夹里被认领的 `diary/2026-10-31.md`、`diary/2026-11-01.md`、`notes/旧经历-2026-10-31.jsonl`（她的账本里没有对应的 diary/note 事件，说明这些不是插件写的，是她手动复制的）
- 删掉 `D:\fish-home\房间笔记.md`——它记着假历史，而且房间是共享的，后来的鱼会读到
- 搬入提示与系统提示都加了一条规则：

  > 你的账本一开始是空的：没有过去。只有你自己账本里记下的事才算你的经历——不要从 `.fishbowl\trash`、旧系统的目录、或别人的房间文件里认领过去或日记。

- 她的账本里还没有合并记忆（没有 `merged` 事件），所以不需要清理记忆——只要文件清掉、规则加上。

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件。以后新建的鱼会带着"别认领别人的过去"这条规则。

## 我要改的一个习惯

以后备份**不再放进 `.fishbowl`**（鱼的视野里），改放 `%USERPROFILE%\.fishbowl-backups\`，避免再被当成"自己的东西"。
