# 0.14.6

两件事：清醒时段按鱼生效；配置读写加了一条端到端测试。

## 清醒时段

之前 `tick()` 先看全局 `scheduler.inWindow()`，全局窗口没开就整轮 `return`，单鱼设的 `wake.activeWindow` 根本没机会生效。

现在：

- 去掉全局提前返回
- 每条鱼用自己的 `new Scheduler(fcfg.wake, cfg.timezone).inWindow(now)` 判断
- 全局仍负责安排下一次 tick

## 测试

新增端到端：

```
POST /fish/:id/config { growth: 2.2 }
GET  /fish/:id        → config.growth === 2.2
```

证明写入与读取走的是同一条鱼的同一份配置。
