# 0.9.1

补上「看 B 站」的申请入口。

## 她为什么说没有申请的口子

会话里她的原话：

> 申请入口只有一个，就是"在 B 站说一句话"那种；刷视频没有对应的申请按钮。

她是**对的**。起因是你说过一句（账本里记着这条 grant）：

> 现在你可以 刷 B 站， 但是需要向我申请

她照着这句话来申请，可当时 `fish_ask_permission` 只支持 `comment.post`，而她的 B 站说话开关又没开——于是被拒，误以为"没有口子"。

## 改了什么

- `fish_ask_permission` 新增动作 `browse`（看一次 B 站）
  - `browse` 需要 `browse.enabled`
  - `comment.post` 需要 `comment.enabled`
  - 两件事的提示分开，不再用"说话"的报错回她
- 看 B 站的工具：如果他的许可里写着"需要申请"
  - 有许可 → 消费许可，正常看
  - 没许可 → **也让她看**，但记一条 `breach`（约定，不是围墙）
- 工具说明改成"能申请两件：browse / comment.post"

## 现在的完整闭环

1. 她说"想看看首页" → 调 `fish_ask_permission(action=browse)`
2. 你点同意 → 签发许可（1 次 / 2 小时）
3. 她调 `fish_bili_look` → 用掉许可，看到内容
4. 如果她没问就看了 → 照样能看到，但状态块和设置页里会留下"没等他同意就做过"

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件。她之前那条 `comment.post` 的请求可以忽略——下次她会用 `browse` 重新申请。
