# 0.9.2

请求卡片的三个问题一起修了。

## 1. 旧请求不再显示

只展示**结构化请求**（带 action 的）。以前那些自动生成的空话（"你点头我再摸机器"）不再出现，也不会再被当成待办。

## 2. 看 B 站的许可按"今天"算

- `browse` 申请：许可有效期到**当天结束**，第二天自动作废
- 次数给到 20 次（"一整天都能看"），而不是一次
- 请求文案直接写明："申请：今天可以刷 B 站，今天有效（到当天结束）"
- `comment.post` 仍是 1 次 / 2 小时

## 3. 不用再进设置页点同意

页面右下角会出现一张小卡片：

```
鲸鲸：申请：今天可以刷 B 站，今天有效（到当天结束）
理由：想看看首页推了什么
                        [不同意] [同意]
```

- 每 20 秒查一次待答请求
- 点同意/不同意直接提交，卡片立刻消失
- 只有结构化请求（有 action）才会弹

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新页面。
