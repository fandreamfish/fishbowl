# 0.12.1

导入提示写错了，不是导入失败。

## 发生了什么

你导出的包没问题：

```
D:\fish\fishbowl-export-20261101-181255-e953
manifest: 4 条鱼（大肥鱼、小肥鱼、鲸鱼娘、程序娘）
creatures/<4 个 id>/ 都在
```

导入提示用的是 `housed`（这次**新安置**的鱼），而不是 `imported`（**实际导入**的鱼）。因为四条鱼本来就有房间，`housed` 是 0，提示就成了"导入 0 条鱼"——看起来像失败，其实四条都已经导入、只是没有新建房间。

## 改了什么

提示改成：

```
导入 4 条鱼；这次新安置 0 条，跳过 4 条（已有房间）
屋子：C:\Users\24358\.fishbowl\home\大肥鱼的屋子
```

## 验证

- 分层 / 接口 / 模块加载检查通过
- 七套测试 exit=0

## 升级

重启插件 + 刷新页面。

真正的搬家（换电脑）时，旧会话不存在，`housed` 才会非 0——那时四条鱼会被安置进「大肥鱼的屋子」。
