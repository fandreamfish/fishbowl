# fishbowl 0.1.0

第一版完成。这一版的重点不是功能堆叠，而是**把"她"和宿主分开**，让每一块都能单独测试、单独搬走。

## 现在有哪些包

| 包 | 层 | 职责 |
|---|---|---|
| `@fishbowl/affect` | 核心（纯函数） | 评价 → 情绪 → 六维偏置；成长率、遗忘窗口、半衰期 |
| `@fishbowl/being` | 个体 | 只追加账本、事件溯源、住处互斥、承诺、许可、日记/纸条/请求 |
| `@fishbowl/memory` | 能力 | 合并记忆、检索（BM25 + 可选向量）、预算渲染、写锁 |
| `@fishbowl/schedule` | 能力 | 清醒节律、主动联系配额、自处 |
| `@fishbowl/voice` | 能力 | 按关系原型的语域规则 |
| `@fishbowl/journal` | 能力 | 日记/纸条/请求的提示词、解析与时间窗 |
| `@fishbowl/bilibili` | 能力 | B 站只读浏览、风控节奏、评论闸门、登录态 |
| `@fishbowl/app` | 应用 | 按鱼配置、评价器、LLM 端口、注入渲染、绑定、改名、回合与唤醒用例 |
| `@fishbowl/adapter-dsh` | 适配器 | 事件订阅、注入、唤醒、工具注册、设置页 HTTP |
| `packages/plugin` | 宿主插件 | DSH 入口与前端设置页 |
| `packages/bridge-qq` | 宿主插件 | OneBot v11 QQ 桥 |

依赖方向由 `scripts/dev/check-layers.mjs` 强制：只能由外往内，跨层依赖直接报错。

## 这一版的能力

- **情绪**：效价 / 唤醒 / 愧疚 / 想念，全部随时间变化（负面半衰期可配），互动会改变它们
- **记忆**：每轮落账、到点整理、预算注入、关键词检索、可选向量检索；`memory_search` 工具
- **作息**：清醒节律、主动联系（有由头才开口）、自处（她可以自己醒来看看/写日记）
- **日记**：一天的最后一件事；时间窗可配；第二天补写昨天
- **上网**：B 站只读浏览（首页/搜索/相关/指定视频）、抽帧、登录态、评论/回复（需授权）
- **能力开关**：每条鱼可以关掉上网 / 在 B 站说话 / 翻记忆；关掉后工具不注册、设置页不显示
- **多宿主**：DSH 插件与 QQ 桥共用同一本记忆账本与同一套情绪
- **按鱼配置**：作息、记忆、上网、评论、日记、半衰期、能力开关，全部按鱼独立

## 不变量（回归测试守住）

1. 账本只追加；投影可删可重算
2. 情绪是纯函数：同账本 + 同时刻 → 同结果
3. 个体 = 一个目录：`creatures/<id>/` 自包含
4. 配置按鱼独立；密钥/登录态不进仓库
5. 插件零依赖（只用 `node:` 内置）
6. 宿主回调绝不外抛

## 测试

```sh
npm run test:all    # 分层检查 + 内核 + 记忆 + 插件 + 上网 + B 站 + QQ 桥
npm run smoke       # 插件激活冒烟（假宿主）
```

## 已知留白

- 旧路径（`src/core/*`、`packages/plugin/lib/*`）保留为 re-export 兼容层，下一版删除
- 向量检索默认关闭，需要真实标注集评测后再决定
- QQ 桥与 DSH 同时写同一账本时仍没有全局限互斥（桥有自己的锁文件）
- `client.js` 仍是单文件，按页面拆组件留到 0.2
